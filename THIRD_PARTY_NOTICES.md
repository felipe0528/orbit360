# Componentes separados

- **telemetry-parser**, [commit a94d7ed](https://github.com/AdrianEddy/telemetry-parser/tree/a94d7ed06929eb9145411227c7f187189b96016f): documentación en código de la estructura INSV y convenciones de calibración contrastadas al escribir `src/insv.js`. MIT OR Apache-2.0; se conserva el [aviso MIT](licenses/telemetry-parser-MIT.txt). El motor no utiliza las tablas ópticas incluidas en ese proyecto ni lo necesita instalado.
- **Insta360 Camera/Media/Metadata SDK y Studio**: pertenecen a sus respectivos titulares. No son necesarios para el motor abierto predeterminado de Orbit360 0.3. El adaptador opcional se configura desde una copia aportada por el usuario. No se incluyen binarios, encabezados, modelos ni implementaciones del SDK. No se encontró una autorización de redistribución dentro del ZIP inspeccionado; este repositorio no presupone ese permiso.
- **FFmpeg**: proceso externo abierto. `npm run setup` descarga el release fijado [ffmpeg-static b6.1.1](https://github.com/eugeneware/ffmpeg-static/releases/tag/b6.1.1), comprueba sus hashes y conserva licencia, procedencia y manifiesto dentro del runtime local. Los builds seleccionados incluyen componentes GPL; su licencia no cambia a MIT. El código fuente de Orbit360 no incluye esos binarios. Véanse [procedencia de los builds](https://github.com/eugeneware/ffmpeg-static#sources-of-the-binaries) y [FFmpeg Legal](https://ffmpeg.org/legal.html).
- **Codex CLI**: herramienta externa con sus propios términos y autenticación. No se distribuye ni se copian credenciales.
- **REA**: herramienta MIT de análisis usada en desarrollo, [morluto/rea](https://github.com/morluto/rea). No se copia su código dentro de Orbit360 y no es necesaria para editar vídeos. El informe identifica la versión y las operaciones ejecutadas.
- **Google Spatial Media**: las especificaciones públicas [V1](https://github.com/google/spatial-media/blob/master/docs/spherical-video-rfc.md) y [V2](https://github.com/google/spatial-media/blob/master/docs/spherical-video-v2-rfc.md) describen los metadatos 360°. Orbit360 contiene una implementación independiente. La herramienta de referencia de Google (Apache-2.0) se utilizó externamente para validar archivos y no se distribuye con la aplicación.

La licencia MIT de Orbit360 no modifica las condiciones de ninguno de estos componentes. Los nombres Insta360 y Codex se usan para identificar interoperabilidad, sin afiliación ni respaldo oficial.
