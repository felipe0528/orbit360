# Contribuir

Ejecuta `npm test` y `npm run check`. Las pruebas de FFmpeg necesitan un ejecutable con libx264, AAC y v360. Mantén Node.js sin dependencias de ejecución innecesarias y separa proveedores LLM del motor de vídeo.

No incluyas vídeos personales, credenciales, configuraciones locales, registros con rutas privadas ni archivos propietarios del SDK. Las nuevas cámaras deben documentarse con modelo, firmware, modo y resultado verificable; un nombre de cámara en una DLL no constituye una prueba de soporte.

Para errores audiovisuales, comparte primero metadatos técnicos y pasos reproducibles. Solo adjunta medios para los que tengas autorización. El código del modelo debe seguir produciendo un plan limitado y validado, nunca comandos arbitrarios.
